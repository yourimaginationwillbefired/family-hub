# Family Hub — Django + DRF + React

Test project built for Spencer. Django + Django REST Framework backend, React (Vite) frontend.

## What's inside
- `backend/` — Django project `config`, app `hub` (SchoolEvent, Package, DigestItem), DRF viewsets at `/api/`
- `frontend/` — React + Vite dashboard (build output served by Django in production)
- `Dockerfile`, `render.yaml` — one-click deploy on Render free tier

## Auth
Login required for both the app and the API (as requested). Create a user:
```
python manage.py createsuperuser
```
Or use the test user from the demo (see chat).

## Run locally
```
cd backend
# create venv, pip install -r requirements.txt
python manage.py migrate
python manage.py seed_hub
python manage.py runserver
# open http://127.0.0.1:8000/
```

## Deploy on Render
1. Push this folder to a GitHub repo
2. In Render: New → Blueprint → point at the repo (uses `render.yaml`)
3. Set `DJANGO_SECRET_KEY` (auto-generated by the blueprint)

Note: seed data is generic examples only — no personal email content.
